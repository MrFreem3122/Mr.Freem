About the project

Running quizzes for our otaku community meant a lot of manual work: reading questions out, collecting answers and counting points for every player. I designed OtaKu Quiz in Figma and built it so we can play together even when everyone is at home, or in a different country.

The host builds a quiz with multiple choice, true or false and free-text questions, then shares a code. Players answer on their phones against a timer and score more for faster answers. The server keeps the answers private and pushes every question, result and leaderboard to all players in real time.

What I built

  • Quiz editor with three question types, images and a timer per question
  • Game rooms with a 4-letter code and a WhatsApp share link
  • Real-time play over WebSockets, with a server written from scratch and no dependencies
  • Speed-based scoring, a leaderboard after each question and a final podium
  • Free-text answers checked without case or accents, with manual validation by the host
  • Automatic reconnection: players who reload or lose signal come back with their score
  • Deployed on Render
