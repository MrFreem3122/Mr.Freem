Multiplayer quiz

A real-time quiz game. A host starts a session, players join from their own device with a code, and everyone sees questions and scores update live.

About the project

The game master creates a quiz session and gets a unique code. Players enter that code to join, then answer each question as it appears on their screen.

A Node.js server keeps every player in sync over WebSockets, so questions, answers and the scoreboard update instantly without refreshing the page.

What I built

  • Session creation with a unique join code
  • Players joining from any device
  • Live questions and answers over WebSockets
  • Real-time scoreboard
