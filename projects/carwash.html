CleanRide

A booking site for home car-wash businesses: customers pick a wash, a day and a time slot in a calendar, then confirm on WhatsApp. The owner manages everything from a phone.

Type
Personal project, reusable for other businesses
Built with
JavaScript, Node.js, PostgreSQL (Neon), HTML, CSS, Render
Status
Online
Visit the site

About the project

Small service businesses often take bookings in WhatsApp chats, which leads to double bookings and lost messages. CleanRide gives customers a clear page where they choose a wash, see which days and time slots are still free, and send a ready-made booking message on WhatsApp.

The time slot is locked on the server as soon as the booking is sent, so two customers can never take the same one. The owner sees every booking by day, confirms it and sends the confirmation to the customer in one tap. I built it as a base: the business name, services, prices, time slots and closed days are all changed from the owner area, so it can be reused for other businesses.

What I built

  • Interactive calendar with closed days, full days and taken time slots
  • Booking in four steps, with a preview of the WhatsApp message
  • Time slots locked on the server, so no double bookings
  • Owner area protected by a code: bookings by day, confirm, cancel, directions
  • Settings for services, prices, time slots and closed days, without touching the code
  • Node.js server with no dependencies, PostgreSQL database on Neon, deployed on Render
